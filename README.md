# SVGConverter - High-Fidelity Raster to Vector Engine

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Website](https://img.shields.io/website?url=https%3A%2F%2Fthevikramsinha.github.io%2Fsvgconverter%2F)](https://thevikramsinha.github.io/svgconverter/)
[![Maintained](https://img.shields.io/badge/Maintained%3F-yes-green.svg)](https://github.com/thevikramsinha/svgconverter/graphs/commit-activity)

**SVGConverter** is a professional, client-side web application that converts raster images (JPG, PNG) into scalable vector graphics (SVG). Built with privacy and performance in mind, it performs all calculations locally in the user's browser without uploading data to any server.

---

## 🚀 Live Demo

**[👉 Launch SVGConverter](https://thevikramsinha.github.io/svgconverter/)**

---

## ✨ Key Features

* **⚡ Instant Vectorization:** Uses the advanced `ImageTracer.js` engine to trace paths and generate nodes in seconds.
* **🔒 Privacy-First Architecture:** Zero server-side processing. Your images never leave your device.
* **🎨 High Fidelity:** Optimized for preserving shapes and colors with intelligent path simplification.
* **📱 Responsive Design:** Fully functional on desktop, tablet, and mobile devices.
* **🔍 SEO Optimized:** Built with semantic HTML5, JSON-LD Schema, and Open Graph tags for maximum search engine visibility.

## 🛠️ Tech Stack

* **Core:** HTML5, CSS3, Vanilla JavaScript
* **Engine:** [ImageTracer.js](https://github.com/jankovicsandras/imagetracerjs) (Client-side tracing)
* **Styling:** Custom CSS variables (No external frameworks for maximum speed)
* **Deployment:** GitHub Pages

## 📦 Installation & Local Development

If you want to run this project locally or contribute:

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/thevikramsinha/svgconverter.git](https://github.com/thevikramsinha/svgconverter.git)
    ```

2.  **Navigate to the directory**
    ```bash
    cd svgconverter
    ```

3.  **Open `index.html`**
    Simply open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari). No build steps or Node.js required!
